### Purpose
To experiment with real-time communication protocol in .NET with SignalR through a multiple Console app project setup. The goal is to test an architectured structured decoupled case of "ping" and "pong" between two Clients and a Server, to learn patterns and resources needed to use and set up SignalR.

⚙️ **Tech stack:** C# and .NET 10

⚛️ **App:** Console
